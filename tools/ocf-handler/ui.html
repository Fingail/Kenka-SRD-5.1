OCF Quest Launcher

Basic 2014 5e demo: Lux and Black Bear. Kanka API access is read-only. Sign in to Dungeon Revealer as GM first.

New test instances start at maximum HP. Refresh keeps existing HP, positions, fog and roll history. Spells and special features are excluded.
